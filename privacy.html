Privacy Policy

Last updated: November 20, 2026

Stillnight Uploader is a personal tool run only on its owner's own computer. It uses Google OAuth to access the owner's own YouTube channels in order to upload videos, set their metadata and schedules, and read channel and video information.

Data accessed through Google APIs is stored only on the owner's computer, is used only for these purposes, and is never sold, shared with, or transferred to any third party.

Stillnight Uploader's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Access can be revoked at any time at https://myaccount.google.com/permissions.
